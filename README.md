E-Inteiler adalah prototype aplikasi produktivitas mahasiswa yang membantu pengguna 
mengelola dan mencatat tugas dari berbagai platform pembelajaran ke dalam satu tempat. 
Aplikasi ini juga memiliki fitur timer Pomodoro yang terinspirasi dari aplikasi seperti 
Forest untuk membantu pengguna tetap fokus saat belajar dan mengerjakan tugas.
Project ini dibuat sebagai proyek akhir dan bukan aplikasi yang benar-benar fully functional. 
Setiap anggota tim mengerjakan satu halaman berbeda dalam aplikasi. Prototype dikembangkan 
menggunakan HTML, CSS, dan sedikit JavaScript untuk menampilkan konsep serta tampilan dasar aplikasi.
